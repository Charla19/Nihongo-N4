Avant de commencer : les formes à reconnaître

Les fiches utilisent ces noms de formes. Le groupe 1 change sa dernière syllabe ; le groupe 2 retire る ; する et 来る sont irréguliers.

FormeGroupe 1 · 書くGroupe 2 · 食べるIrréguliers
Base en ます書き食べし・来（き）
て / た書いて / 書いた食べて / 食べたして / した
来て / 来た
Négation書かない食べないしない / 来ない
Condition en ば書けば食べればすれば / 来れば
Volitive書こう食べようしよう / 来よう
Potentielle書ける食べられるできる / 来られる
Passive書かれる食べられるされる / 来られる
Causative書かせる食べさせるさせる / 来させる

Pour tous les verbes du groupe 1 : la forme en て/た suit la terminaison : う・つ・る → って/った ; む・ぶ・ぬ → んで/んだ ; く → いて/いた (exception : 行く → 行って/行った) ; ぐ → いで/いだ ; す → して/した. Pour ない, passe à la ligne en あ (買う → 買わない) ; pour ば et la potentielle, à la ligne en え ; pour la volitive, à la ligne en お.

Pour les adjectifs en い : 高い → 高く・高くない・高ければ. Pour ceux en な : 静か → 静かに・静かではない・静かなら. Certaines formes particulières sont précisées dans leur fiche.
